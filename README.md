# Offensive and Defensive Cybersecurity — Politecnico di Milano
CTF challenges for the *Offensive and Defensive Cybersecurity* course at Politecnico di Milano (A.Y. 2024/2025), on a x86 Linux operating system, covering the following topics:
- Kernel exploitation
- Heap exploitation
- Stack-based exploitation and ROP chaining
- Race conditions
- Shellcode
- Reverse engineering
- Fuzzing
- Symbolic execution
- Malware analysis
